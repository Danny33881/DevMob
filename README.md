При запуске приложения вы попадете на экран "Начать активность"

На нем выберите тип активности и нажмите "Начать" (можно повторить несколько раз с разными типами активностей)

Нажмите на фиолетовую стрелочку в левом верхнем углу экрана. Вы перейдете к экрану "Мои активности", где отображаются все активности пользователя. Там должны быть те активности, которые вы только что добавили. 

При необходимости нажмите на фиолетовый кружок с треугольником в правом нижнем углу экрана и снова перейдите к созданию активностей.
